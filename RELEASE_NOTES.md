# Java to C++ Translator v1.0.3

A Windows desktop release of this student/portfolio Java-to-C++ transpiler, supporting a limited Java subset rather than the full language.

- Windows installer with the Java runtime bundled; no separate Java installation required.
- Fixed the packaged JavaFX launch issue, with a working application launcher and Start menu shortcut.
- Tested direct upgrade from v1.0.1 without uninstalling first; one Installed Apps entry remains.
- In-app update checker: use the top-right **↻** button to check for future releases.
- Validation passed: 110 translator checks, 9 updater/version checks, packaged and installed launch tests, and translation through the desktop interface.

Download the Windows `.exe` installer from this release's **Assets** and run it. Existing v1.0.1 users can install directly over their current installation. Windows may request administrator approval.

**Windows SmartScreen:** The installer is currently unsigned. Windows may show “Windows protected your PC.” If you downloaded it from this official GitHub release, choose **More info → Run anyway** to continue.
